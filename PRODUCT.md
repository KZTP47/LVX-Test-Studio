# LVX Test Studio

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Nontechnical testers create meaningful automated checks visually. Experienced developers can inspect and refine parameters, source, dependencies and complete run evidence. The owner confirmed this workflow on 2026-10-24.

## Operating context
An existing Windows Electron application with a browser preview. Local workspaces, visual web tests, native test runners, pipelines, datasets and security evidence are separate capabilities with explicit readiness requirements. Browser preview cannot promise desktop execution.

## Product principles
- Choose a target, build visible steps, run, understand the result, inspect evidence.
- Use clear defaults and progressive disclosure without discarding advanced configuration.
- Missing prerequisites and incomplete evidence remain visible failures or unavailable states.
- Empty workspaces contain no automatically inserted demonstration tests.
- Keep original records recoverable and detect conflicting edits.

## Brand commitments
LVX Test Studio name and the owner-supplied pink octopus mascot. Preserve the original Machina Aero home as the single application frame. Integrate all newer tools directly into that frame. The AI board follows the supplied dark teal Nexus reference, with full-screen and independent chats. Use semantic SVG controls and visible action labels.

## Accessibility
Keyboard navigation, meaningful dialog names, focus return, readable results, a list alternative to graph editing and usable layouts at 200% zoom.

## Ownership and distribution
The owner selected MIT on 2026-10-24. No Windows signing identity has been supplied. Preparing a signing pipeline does not make a binary signed or prove a remote CI job passed.
